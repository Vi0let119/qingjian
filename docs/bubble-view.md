# 气泡视图 · 交互模型

## 为什么这样设计

旧的边框三栏布局把界面切成固定的格子，信息被关在格子里。
气泡视图把信息放回一个可漫游的空间：**位置本身携带含义**（哪一层、离中心多远、和谁挨着）。

但气泡不能用来写字——拖动、缩放、涟漪都会打乱光标与输入法选区。
所以边界很明确：

> **气泡是浏览与定位层；点开气泡后，动画展开成真正的书写纸面。**

这样既有空间感的视觉与手感，又不牺牲书写的可靠性。

## 三个层级（面包屑也按这三层）

1. **笔记本层**：主界面第一屏。每个笔记本是一个气泡，大小按笔记数量呈现
2. **笔记层**：点开一个笔记本气泡，涟漪扩散后其余气泡退场，该笔记本的笔记气泡浮出
3. **书写层**：点开笔记气泡，气泡放大成纸面，进入编辑器

返回：按 Esc 或点面包屑回上层；气泡视图与列表视图可随时切换。

## 空间规则

- 画布可拖动（空白处按下拖），滚轮滚动，双击空白回中心
- 气泡按"力导向 + 圆环"混合排布：重要的靠中心，同类靠近
  - 简化实现：环形排布 + 基于笔记数的半径微调，保证稳定可预测（不引入物理引擎依赖）
- 气泡大小：`minSize + sqrt(count) * k`，限制在 [96, 200]
- 气泡之间的最小间距由半径决定，避免重叠

## 动效

| 事件 | 效果 |
|---|---|
| 进入视图 | 气泡从中心向外逐个"浮起"（scale 0.6→1，opacity 0→1，stagger 40ms） |
| hover | 气泡轻微上浮 2px + 光晕扩散；内部文字轻微放大 |
| 点击 | 涟漪：一圈墨色从点击点向外扩散并淡出（500ms），随后层级切换 |
| 层级切换 | 旧层气泡收缩淡出，新层气泡从被点处向外展开 |
| 返回 | 逆过程 |
| 打开笔记 | 气泡放大到铺满内容区（FLIP），期间其他气泡退场 |
| 待办/无笔记 | 空气泡显示虚线轮廓与提示，点击直接新建 |

全部尊重 `prefers-reduced-motion`：关闭位移与缩放，只留透明度变化。

## 视觉

沿用 v2「纸页」的墨色与绿：
- 气泡是**纸上的墨点**：极淡的墨色同心圆边缘（不是实心球，避免廉价 3D 感）
- hover 时边缘变实、内部染上极淡绿
- 文本：笔记标题（正文级），下方小字显示修改时间或字数
- 背景保留桌面纤维纹理

避免：玻璃拟态、渐变球、发光边框、阴影投到气泡上方（保持一致光源：光从左上来）
