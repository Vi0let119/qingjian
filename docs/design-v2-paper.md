# 轻笺 · 视觉方向 v2「纸页」

## 诊断（当前为何显得廉价）

1. 只有 白 / 深灰 / 一点绿，色彩没有体系，绿色孤立不参与交互
2. 工具栏用 B/I/U 字形按钮 + 灰框图片按钮，三种风格混搭，90 年代富文本感
3. 层级只靠字号，时间与标题几乎同级；元素分组靠默认排列
4. 深色系统标题栏与纯白内容硬切
5. 零动效：所有状态硬切换
6. 间距无栅格节奏

## 方向：纸页（Paper Leaf）

**隐喻**：一张有厚度的书写纸。不是"便签 App 的皮"，而是真的把纸张的物质感
（纤维、压印、叠放、微微卷边）翻译成界面语言。

与 v1「植物园·纸张」的区别：
- v1 是"纸上画了植物"（装饰性）
- v2 是"界面本身是纸"（结构性）——层次来自纸张的**叠放与阴影**，不靠边框和色块

## 视觉核心

- **物质感**：极轻的双层阴影（近距硬边 + 远距柔光）表达"纸浮在桌面上"，替代硬边框
- **压印字**：标题与主色文字用 1px 内阴影，像铅字压进纸里（Letterpress）
- **纤维**：极淡的噪点纹理叠在纸面上，只在近距离可见
- **色彩**：以墨色为主（ink scale 7 级），绿只用于唯一的主操作与当前状态；
  点缀用"晒干的草黄"而不是鲜橙
- **字体**：中文正文系统无衬线（可读性），标题与时间用衬线（书写感），数字用等宽感

## 动效（轻量、有目的）

1. 窗口入场：纸片"落下"（translateY + scale 0.985→1，opacity，560ms 弹性缓动）
2. 列表项：hover 时左侧出现 2px 墨条，从中心向两端生长（scaleY 0→1）
3. 按钮：按下 scale 0.96，hover 抬升 1px + 阴影加深
4. 保存状态：点从空心变实心的过渡 + 轻微脉冲，而不是整行闪烁
5. 工具栏按钮：hover 时背景圆角块从下方"浮起" 1px
6. 碎片窗口：保存成功时右上角一点绿光晕"呼吸"一次
- 全部尊重 `prefers-reduced-motion`

## 信息层级

- 侧栏：品牌 → 主操作（碎片）→ 笔记本树 → 底部状态/设置
- 主区：标签页（纸边）→ 工具栏（墨色细线分隔）→ 书写区（纸面）
- 碎片小窗：时间胶囊 + 状态点 + 一个主操作

## 避免

- 大色块、渐变光晕、玻璃拟态（会重新变廉价）
- emoji 图标、字形 B/I/U（换成真正的矢量图标）
- 无意义的装饰插画
- 动效超过 600ms、同时动画超过 3 个属性
